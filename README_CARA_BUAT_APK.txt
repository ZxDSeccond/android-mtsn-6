CARA MEMBUAT FILE .APK DALAM 3 MENIT DI ANDROID STUDIO:
--------------------------------------------------------------------
1. Ekstrak file ZIP ini ke komputer Anda (misal: C:\CBT-MTsN6-Solok).
2. Buka software "Android Studio".
3. Pilih "Open" dan arahkan ke folder hasil ekstrak tersebut.
4. Tunggu Gradle sync selesai.
5. Klik menu atas: "Build" -> "Build Bundle(s) / APK(s)" -> "Build APK(s)".
6. Selesai! File "app-debug.apk" atau "app-release.apk" siap di-install di HP siswa.
