# Cara pakai logo MTsN 6

Taruh file PNG berikut di folder ini:

android/app/src/main/res/drawable/mtsn6.png

Pastikan file PNG:
- format: PNG
- nama file: mtsn6.png
- ukuran ideal: 512x512 atau 1024x1024
- background transparan atau sesuai desain logo

Setelah file ditaruh, project akan otomatis memakai logo tersebut sebagai icon aplikasi.
